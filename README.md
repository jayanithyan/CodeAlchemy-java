## 🔥 Important DSA Patterns

### Two Pointers

```text id="v5x3na"
left  → → → → 
             ← ← ← right
```

Useful for:

* Sorted arrays
* Pair problems
* Triplet problems
* Palindromes
* Array manipulation

---

### Sliding Window

```text id="5j1q2x"
[ left -------- right ]
```

Useful for:

* Subarrays
* Substrings
* Frequency problems
* Maximum/minimum window problems

---

### Hashing

```text id="8d2z0p"
Input
  ↓
HashMap / HashSet
  ↓
Fast Lookup
  ↓
Optimized Solution
```

Useful for:

* Frequency counting
* Duplicate detection
* Two Sum
* Grouping
* Prefix Sum problems

---

### Binary Search

```text id="j8v4m2"
        Search Space
┌─────────────────────────┐
│  L          M          R │
└─────────────────────────┘
             ↓
       Eliminate half
```

Useful for:

* Sorted arrays
* Search-space problems
* Optimization problems
* Lower/upper bound techniques

---

### Recursion & Backtracking

```text id="s3q7wn"
             Problem
                │
        ┌───────┴───────┐
        ↓               ↓
     Choice 1        Choice 2
        │               │
        ↓               ↓
     Explore          Explore
        │               │
        └───────┬───────┘
                ↓
             Backtrack
```

Useful for:

* Subsets
* Permutations
* Combinations
* Trees
* Constraint problems

## 📊 Complexity

Understanding complexity is an important part of the repository.

| Complexity   | Description  |
| ------------ | ------------ |
| `O(1)`       | Constant     |
| `O(log n)`   | Logarithmic  |
| `O(n)`       | Linear       |
| `O(n log n)` | Linearithmic |
| `O(n²)`      | Quadratic    |
| `O(2ⁿ)`      | Exponential  |

The objective is to move from a working solution toward an efficient solution whenever possible.

---

## 💡 From Brute Force to Optimization

A typical improvement process looks like:

```text id="k4m6qp"
Brute Force
    ↓
O(n²)
    ↓
Identify Repeated Work
    ↓
Choose Better Data Structure
    ↓
Hashing / Two Pointers / Sliding Window
    ↓
Optimized Solution
    ↓
O(n)
```

This repository is intended to document that progression in problem-solving ability.

## 🚀 How to Use This Repository

If you're learning DSA, don't immediately copy the solutions.

Use this repository as a reference after attempting the problem yourself.

```text id="g4v2sk"
3. Attempt your own solution
4. Identify the DSA pattern
5. Implement in Java
6. Analyze Time & Space Complexity
7. Compare with other approaches
8. Revisit the problem later
```

> **Try first. Look later. Understand always.**
